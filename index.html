How does it work?

We try street junctions as goodbye points, using shortest paths to get there and to each destination. We choose the candidate with the most shared walking that fits both time limits, without backtracking loops.

Times assume a steady 4.9 km/h. This is a small map experiment: crossings, opening hours, accessibility and live closures aren’t modelled. Use it to explore an idea, rather than for turn-by-turn navigation.
